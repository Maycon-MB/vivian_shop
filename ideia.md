# Projeto: Substituir Elo7 (Loja de Papelaria & Produtos Adaptados)

## 🎯 Visão Geral
Desenvolver uma plataforma de e-commerce própria para substituir a dependência do Elo7, focada em dois nichos específicos: Papelaria e Produtos para PCD (Crianças e Adolescentes). O grande diferencial competitivo será a **Automação de Ponta a Ponta**: desde a postagem no Instagram até a geração da etiqueta de envio.

---

## 🚀 Diferenciais do Projeto (O Valor para a Cliente)
1. **Independência de Plataforma:** Fim das taxas abusivas do Elo7 e controle total sobre a marca.
2. **Marketing Autônomo:** Integração com a engine de automação de posts (Instagram) para manter o perfil ativo sem esforço da cliente.
3. **Logística Simplificada:** Botão de "Gerar Etiqueta" com código de barras integrado diretamente com APIs de frete (Melhor Envio).
4. **Foco em Confiança:** Design premium focado em acessibilidade e prova social para converter visitantes em clientes.

---

## 🛠️ Pilares Técnicos (Stack)
- **Frontend:** Next.js (SEO e Velocidade).
- **Estilização:** Tailwind CSS (Moderno e Responsivo).
- **Backend/Database:** Supabase (Escalabilidade e Facilidade).
- **Pagamentos:** Mercado Pago (Pix e Cartão).
- **Frete:** API Melhor Envio (Cálculo e Impressão de Etiquetas).

## 📋 Funcionalidades Principais

- [ ] Filtros de busca inteligentes.
- [ ] Checkout otimizado (One-page checkout).
- [ ] Botão flutuante de WhatsApp para suporte humano (Aumenta confiança).

### 🖥️ Painel Administrativo (Dashboard)
- [ ] Gestão de Estoque e Preços.

### 🤖 Integração com Automação
- [ ] Webhook para disparo de novos produtos para o Instagram.
- [ ] Agendamento automático de posts educativos sobre produtos PCD (Gera autoridade).

---

## 🛡️ Estratégia de Confiança & Conversão
A "falta de confiança" em sites novos é combatida com:
1. **Prova Social Automatizada:** Exibição de fotos reais de clientes (integrado com Instagram).
2. **Transparência no Frete:** Rastreamento do pedido enviado automaticamente via WhatsApp/E-mail.
3. **Design Acessível:** Interface limpa que respeita as normas de acessibilidade (especial para o público PCD).
